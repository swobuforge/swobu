# Hermes Agent

Use the Workspace Connect page in the Web Operator or the
[reviewed Connect workflow](admin-mcp.md) with client `hermes`.

Connect selects Hermes' custom OpenAI-compatible backend, points it at the
workspace endpoint, and chooses Swobu's `default` model. Existing unrelated
Hermes settings remain owned by Hermes.

CLI apply requires an exact Workspace, private intent file and literal scoped
confirmation, including replacement of different main-model configuration.
