# Claude Code

1. Run `swobu` and open the Workspace Connect page in the Web Operator.
2. Select `Claude Code`, review the endpoint change, and apply.
3. Run Claude Code normally. Web Operator Activity provides runtime traffic proof.

For CLI use, follow the [reviewed Connect workflow](admin-mcp.md) with client
`claude`, an exact Workspace, private intent file and literal local confirmation.
Replacement is part of that review, not a `--replace` bypass.

Connect points Claude Code at the workspace endpoint and enables workspace
model discovery. Existing unrelated Claude Code settings remain owned by
Claude Code.
